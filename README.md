# cognix

Cognix aims to be a local-first autonomous coding agent. The
[long-term product vision (Issue #3)](https://github.com/takahirox/cognix/issues/3)
provides the broader context; the [MVP v0.1 specification](docs/mvp.md) scopes the
first release to a single-agent CLI with bounded edit-and-test loops.

This repository currently contains specifications, contributor guidance and
templates. The MVP is not implemented, the implementation stack remains
undecided, and there are no application setup, build or test commands yet.
